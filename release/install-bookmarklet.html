Export Claude Session

Version 1.0.0. Saves a claude.ai chat, with every message, pasted image, file and artifact, to one .zip on your computer.

1. Install (once)

Show your bookmarks bar (Ctrl+Shift+B, or Cmd+Shift+B on Mac), then drag this button onto it:

Export Claude Session

Can't drag? Click , add a new bookmark named "Export Claude Session", and paste the code as its URL.

2. Export a chat

  1. Open the chat on claude.ai in this browser.
  2. Recommended: type /export-session in that chat. Claude writes a handoff brief (goals, decisions, where you left off, the memory it was using).
  3. Click the Export Claude Session bookmark. A progress box appears top right, then the .session.zip downloads.

3. Continue in a new chat or Cowork task

  1. Start a new chat or Cowork task with the session-transfer plugin installed.
  2. Attach the zip and say import this session.

Privacy

It runs only in your browser tab and reads claude.ai with your existing sign-in. Nothing is sent anywhere else. The zip contains the whole conversation, so keep it private.

It uses claude.ai's internal web API, the same one the site uses. If claude.ai changes it, the export can stop working until this tool is updated.
